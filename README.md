# Cookies — «Горішки»

Односторінковий сайт приватної майстрині, яка виготовляє фірмові горішки з пісочного тіста та згущеного молока.

## Статус

Поточна фаза: discovery → design system.

У репозиторії зафіксовано бриф, дизайн-напрям, архітектурні рішення, критерії готовності та правила для подальшої роботи AI-агента. Відкриті бізнесові дані позначені як `TBD` і не повинні вигадуватися в коді чи текстах сайту.

## Документація

- [PROJECT.md](PROJECT.md) — узгоджений бриф і межі першої версії.
- [REQ.md](REQ.md) — вимоги, сценарії та acceptance criteria.
- [CONTEXT.md](CONTEXT.md) — технічний контекст і правила репозиторію.
- [DESIGN.md](DESIGN.md) — візуальна система та UI-правила.
- [TDD.md](TDD.md) — мінімальна стратегія перевірки якості.
- [STATE.md](STATE.md) — поточний стан і наступні кроки.
- [PROMPT.md](PROMPT.md) — робочі інструкції для AI-агента.
- [docs/ASSETS.md](docs/ASSETS.md) — правила production і reference assets.

## Важливе правило

Головне hero-зображення має бути реальним фото горішків від майстрині. Тимчасові або згенеровані зображення допустимі лише для макета й другорядних декоративних блоків.
