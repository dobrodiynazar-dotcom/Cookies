# Горішки

Перший макет односторінкового сайту домашньої кондитерської. Основа — узгоджені сім секцій, темна тепла палітра й фото замовника. Невідомі комерційні дані не підмінено вигаданими.

## Запуск

```bash
pnpm install
pnpm dev
```

Документи: PROJECT.md (бриф), REQ.md (вимоги), DESIGN.md (візуальний напрям), CONTEXT.md (технічний контекст), STATE.md (стан), docs/ASSETS.md (зображення).

Перед публікацією потрібні актуальні контакти, ціни, ваги, історія майстрині та відгуки. Реальний домен для sitemap теж поки не встановлений.
