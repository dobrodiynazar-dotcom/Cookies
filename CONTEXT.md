# CONTEXT

Односторінковий статичний сайт на Next.js 16, TypeScript та локальному CSS. Контент і фото у цьому репозиторії; без бази даних, кошика, форми чи інтеграції оплати. Публікація планується через Vercel після перегляду.

PROJECT.md визначає факти і порядок секцій. REQ.md — вимоги; DESIGN.md — напрям; docs/ASSETS.md — надані фото; STATE.md — актуальний стан. Невідомі дані не слід видавати за факти. Майбутні підтверджені контакти, ціни та ваги треба додати перед публікацією.

Візуальний референс Honeybear допомагає з ритмом та плавними переходами. Їхні активи, тексти й конкретне оформлення не переносити.
