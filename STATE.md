Правило проєкту: дизайн і погодження ведемо mobile first, секція за секцією згори вниз. Desktop-адаптацію окремо переглянемо пізніше; зараз вона має залишатися зручною та responsive, без окремого полірування композиції.

Постійне правило локального preview: канонічний checkout — `D:\Work Cookies\Cookies-codex`, робоча гілка — `redesign/honeybear-direction`, а єдина адреса preview — `http://localhost:3000/`. Не створювати окремий worktree або clone для user-facing preview і не переходити на інший порт. Перед запуском перевіряти checkout, гілку та незакомічені зміни. Якщо порт 3000 зайнятий, можна зупинити лише підтверджений застарілий Cookies-сервер; процес іншого проєкту є блокером. Після push користувач оновлює VS Code checkout командами `git pull --ff-only origin redesign/honeybear-direction`, потім `pnpm dev`.

Новий порядок, факти та візуальний напрям записані у PROJECT.md, REQ.md і DESIGN.md. Отримано шість зображень, описаних у docs/ASSETS.md.

Перший макет реалізований як Next.js сторінка: сім секцій, дві картки пакування в керованому слайдері, адаптивний CSS, українські підписи. `pnpm typecheck`, `pnpm lint`, `pnpm build` пройшли. Mobile Hero і responsive-композиція перевірені у локальному production-preview на ширинах 360, 390, 430 px та на desktop; горизонтального overflow немає.

Новий mobile Hero використовує наданий вертикальний ролик `IMG_6128.MOV`, перекодований без зміни початку в web-сумісний H.264 MP4 із first-frame poster. Усі CTA замовлення та контактний CTA спрямовані на Instagram `milyami._`. Додано доступне mobile menu, яке відкривається й закривається тим самим hamburger.

Поточне погоджене оформлення Hero: рівно один mobile viewport; незмінні відео, crop і легке затемнення; Lora у прямому накресленні; ліва композиція з домінантним «Горішки», добре відділеним підзаголовком та компактним CTA з відкритими протилежними кутами. Header на mobile — темно-бордовий, із тонким карамельним hamburger та простою текстовою CTA; desktop показує секційну навігацію й текстову CTA без wordmark. Інструкція зі скриншота про білий X — артефакт кадрування, X не додавати.

Поточне правило шрифтів: лише Lora, upright, ваги 400/500/600; відповідні компоненти зберігають однакову вагу на мобільному й desktop. Фактично завантажені Lora font faces потрібно перевіряти в браузері — одного `font-family` у computed style недостатньо. Header використовує теплий caramel-gold акцент. Hero CTA має прозорий 2px open-frame із проміжками у верхньому лівому та нижньому правому кутах і заокругленими з’єднаннями у верхньому правому та нижньому лівому; позиція, розмір, текст і призначення CTA не змінюються.
