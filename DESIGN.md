## 1. Design concept

Світлий сучасний editorial-мінімалізм для одного кондитерського продукту. Сторінка має відчуватися як світле печиво, масло, згущене молоко, ванільний крем, мед і м’яка карамель — цілісний брендований досвід, а не інтернет-магазин.

Візуальна пропорція: 80% чистоти й стриманості, 20% виразності через помірні serif-заголовки, асиметрію, polaroid-фотографії та легкі картки відгуків.

## 2. Color tokens

Використовувати лише теплу світлу систему. Значення зафіксовані в `src/styles/tokens.css`:

- `cream` — `#F6EFE3`, теплий кремовий фон.
- `oat` — `#ECE1CF`, вівсяно-бежевий.
- `butter` — `#E5D3B2`, масляний тон.
- `sand` — `#D8BF93`, пісочний.
- `gold` — `#C6A272`, приглушене золото.
- `caramel` — `#B87543`, м’які акценти та CTA.
- `text` — `#96582F`, читабельний запечено-цукровий текст.
- `heading` — `#A56237`, помірні заголовки.
- `line` — `#D9C5A6`, тонкі розділювачі.

Заборонено: фіолетовий, сливово-бордовий, шоколадний, темно-коричневий, чорний, сірий, оливковий, темні фонові блоки, холодні нейтралі, яскравий синій, кислотні кольори й чистий яскраво-червоний.

## 3. Typography

- Headings: `Palatino Linotype` / `Book Antiqua` / Georgia — serif-стек із українською кирилицею; виразний, але не display-масштаб.
- Body: `Segoe UI` / Aptos / Arial — чистий sans-serif-стек із українською кирилицею.
- Не використовувати uppercase як базовий стиль і не робити текст більшим за зміст.

## 4. Layout

- Mobile-first.
- Hero: асиметричний, із помірним заголовком «Горішки» та фото в полароїдній рамці.
- Фото: вершково-біла полароїдна рамка, дуже легка тепла тінь, невеликий поворот; portrait ratio 4:5 або 3:4; `object-position: center`.
- Секції можуть мати різний ритм і легке накладання, але контент має залишатися зрозумілим.
- Контейнер і відступи fluid; не допускати горизонтального scroll.
- Sticky-header: тонкий, ненав’язливий, з активним станом якірного пункту.

## 5. Sections

1. `Hero`: короткий title, tagline, CTA й реальне фото горішків.
2. `About`: title і один змістовний рядок прямо на фоні; поруч — три чисті polaroid-плейсхолдери для майбутніх фото процесу й пакування.
3. `Product`: єдине світле фактурне паперове полотно; ліворуч порожня композиційна зона для майбутніх вирізаних горішків, праворуч — короткий текст «Рецепт тепла».
4. `Special moments`: три polaroid-фотокартки з короткими підписами; без accordion чи інтерактивного розкриття.
5. `Reviews`: кілька легких білих карток із короткими нейтральними mock-станами до появи підтверджених відгуків.
6. `Order`: два рівноцінні напрями — приватне замовлення та співпраця з кав’ярнями; на desktop їх розділяє коротка вертикальна лінія.

## 6. Components

- `Header`: logo/name, anchor links, primary CTA.
- `Button`: primary rounded CTA, visible focus, reduced-motion friendly.
- `PolaroidImage`: frame, rotation variant, responsive crop, alt text.
- `FutureProductComposition`: порожня зона для майбутніх real-photo вирізок без рамки, прямокутного placeholder-а чи текстової підкладки.
- `PhotoPlaceholder`: чиста біла полароїдна картка без тексту всередині, для майбутніх реальних фотографій.
- `MomentList`: три статичні сценарії використання продукту.
- `OrderDirections`: два окремі блоки, розділені великою паузою та тонкою лінією.
- `ReviewCard`: легка біла картка; короткі mock-тексти дозволені лише до появи підтверджених відгуків.

## 7. Motion

- `prefers-reduced-motion` обов’язково поважати.
- Плавна поява секцій, делікатний hover і невеликий рух polaroid-карток.
- Без агресивного паралаксу, різких scale-ефектів і важких переходів.

## 8. Image rules

- Hero: тільки реальне фото майстрині.
- Не копіювати зображення з референсних сайтів.
- Для кожного approved image мати змістовний український `alt`.
- Не замінювати майбутні вирізані об’єкти прямокутними фото, картками або mock-плейсхолдерами.

## 9. Accessibility

- Семантичні `header`, `nav`, `main`, `section`, `footer`.
- Кнопки й посилання доступні з клавіатури.
- `:focus-visible` має бути помітним.
- Перевірити контраст запечено-цукрового тексту `#96582F` на світлому кремовому фоні.
- Не передавати зміст лише через колір або анімацію.
