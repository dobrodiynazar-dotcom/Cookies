## 1. Design concept

Світлий сучасний editorial-мінімалізм для одного кондитерського продукту. Сторінка має виглядати як цілісний брендований досвід, а не як інтернет-магазин.

Візуальна пропорція: 70% чистоти й стриманості, 30% виразності через великі заголовки, асиметрію, полароїдні фото та м’які накладання.

## 2. Color tokens

Точні значення затвердити після першого visual pass. Початкові ролі:

- `cream-canvas`: молочно-кремовий фон.
- `sand`: пісочний акцент.
- `caramel`: теплий карамельний акцент.
- `cocoa`: темний какао для основного тексту.
- `plum-muted`: приглушений сливово-бордовий для малих акцентів.
- `paper-white`: білий для полароїдної рамки.
- `line-soft`: світла тонка лінія.

Заборонено: яскравий синій, кислотні кольори, чистий яскраво-червоний, надлишок чорного та строкаті фони.

## 3. Typography

- Display: сучасний жирний grotesk/display-шрифт із підтримкою української кирилиці.
- Body: нейтральний читабельний sans-serif із хорошими українськими гліфами.
- Accent: не використовувати рукописний шрифт як основний стиль.
- Hero wordmark — найбільший текст на сторінці; не використовувати display-шрифт для дрібних UI-елементів.
- Підтвердити конкретні web-safe або open-source шрифти до реалізації.

## 4. Layout

- Mobile-first.
- Hero: асиметричний, із великим «ГОРІШКИ» та фото, яке частково перекриває заголовок.
- Фото: біла полароїдна рамка, м’яка тінь, невеликий поворот; portrait ratio 4:5 або 3:4; `object-position: center`.
- Секції можуть мати різний ритм і легке накладання, але контент має залишатися зрозумілим.
- Контейнер і відступи fluid; не допускати горизонтального scroll.
- Sticky-header: тонкий, ненав’язливий, з активним станом якірного пункту.

## 5. Sections

1. `Hero`: wordmark, короткий placeholder tagline, CTA, реальне фото горішків.
2. `About`: коротка історія майстрині, фото-картки або чесні placeholders до появи фото.
3. `Product`: смаковий опис, склад, пакування, вага, ціна, алергени — тільки підтверджені дані.
4. `Reviews`: картки підтверджених відгуків; до цього — підготовлений empty state або секція без вигаданих цитат.
5. `Order`: CTA, контакти, соцмережі, фото пакування/продукту.

## 6. Components

- `Header`: logo/name, anchor links, primary CTA.
- `Button`: primary rounded CTA, visible focus, reduced-motion friendly.
- `PolaroidImage`: frame, rotation variant, responsive crop, alt text.
- `SectionLabel`: small editorial label.
- `ProductDetails`: typed facts list.
- `ReviewCard`: only approved content.
- `FooterContact`: order link and social links.

## 7. Motion

- `prefers-reduced-motion` обов’язково поважати.
- Плавна поява секцій, делікатний hover і невеликий рух polaroid-карток.
- Без агресивного паралаксу, різких scale-ефектів і важких переходів.

## 8. Image rules

- Hero: тільки реальне фото майстрині.
- Не копіювати зображення з референсних сайтів.
- Для кожного approved image мати змістовний український `alt`.
- Декоративні placeholder-и чітко відокремити від фінальних assets і замінити перед release.

## 9. Accessibility

- Семантичні `header`, `nav`, `main`, `section`, `footer`.
- Кнопки й посилання доступні з клавіатури.
- `:focus-visible` має бути помітним.
- Перевірити контраст cocoa/cream та accent-текстів.
- Не передавати зміст лише через колір або анімацію.
